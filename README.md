# 校园生食食品安全知识挑战

答题网址：https://djzkqb.github.io/campus-raw-food-quiz/

科普正文：https://djzkqb.github.io/campus-raw-food-quiz/article.html

成绩管理：https://djzkqb.github.io/campus-raw-food-quiz/admin.html

10 道单选题，每题 10 分，选项随机排序，逐题展示解释及官方来源。完成后可以自愿提交成绩。不提交也能阅读解析。GitHub Pages 托管网页，云端成绩服务使用 Sites + D1 持久保存；发布者电脑关闭不会影响在线收集。

## 成绩与隐私

提交前需主动勾选同意。保存浏览器生成的匿名编号、可选昵称、10 题答案、总分、题目版本、服务器时间和回执编号。页面不主动收集姓名、学号、手机号或定位。答题者可凭回执向活动负责人申请删除。

分数由云端按固定题目版本重新核算。同一轮重复提交按唯一回执去重；重做测验是新一轮。匿名编号保存在浏览器中，换设备或清除数据会更换编号，所以匿名编号数不等于人数。题目答案和解析公开，不能作为正式考试或严谨前后测效果的依据。公开端点不是防机器刷分系统。

管理页需持管理口令，可查看所有明细、按每个匿名编号首次提交筛选、下载 UTF-8 CSV、删除单条记录。口令仅在页面内存中使用，退出或关页后重新输入。管理口令和后端签名密钥均不在这个公开仓库中。请在活动结束完成汇总后清理不再需要的明细。

## 文件

- `index.html` / `app.js`：答题与提交。
- `article.html`：扩充后的完整科普正文。
- `content.js`：题目、解析和参考来源。
- `admin.html` / `admin.js`：受口令保护的成绩管理界面。
- `score-config.js`：公开成绩服务地址与题目版本，不含密钥。

直接打开离线副本可以练习、阅读；在线收集请从上方 GitHub Pages 网址进入。刷新或关闭页面会丢失尚未提交的本轮状态；已收到“已保存”回执的成绩保存在云端。

题目修改时，应同步更新后端答案表并启用新的题目版本，保留旧记录的解释方式。若更换后端域名，应同步更新 `score-config.js` 和后端允许的前端来源。不要将成绩 CSV 或管理口令提交到公开仓库。

仅为一般食品安全风险科普，不对具体食品、品牌或产品作安全判断。正文的官方来源核对于 2026-11-21；没有虚构活动、人数或调查成果。
