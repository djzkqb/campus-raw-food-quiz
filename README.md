# 校园生食食品安全知识挑战

主题：“生”鲜有风险，入口需谨慎。

10道单选情景题，逐题解析、计分、错题回顾和重做；另附完整科普文章及官方参考链接。

## 使用

- index.html：互动测验。
- article.html：扩充正文和参考资料。
- content.js：题目、答案与来源；每题与正文同编号知识点对应。
- app.js / style.css：交互与视觉。

无构建步骤、无外部脚本、无后台、无成绩上传或个人资料表单。刷新或关闭页面后本轮状态重置。GitHub Pages 提供静态托管，发布者电脑关闭不影响访问。

图片为AI生成情景示意，不对应具体产品。文章为一般风险科普，不是产品检测或诊疗意见。知识内容核对于2026-11-21。

## 发布

GitHub Pages 从 main 分支根目录发布。
